# 虚拟矿脉量产与钻探 Y 轴配置

本文为主世界虚拟矿脉提供量产、地质分布与多重噪声筛选建议。筛选条件不绑定具体 Minecraft 群系，以便随世界预设或数据包中的群系配置变化而复用。矿区只使用原版地表参数点，洞穴与深暗之域专用参数点不参与判定。

## 参数说明

- `C`：大陆性（Continentalness）
- `E`：侵蚀度（Erosion）
- `D`：多重噪声的深度（Depth），不是方块高度。
- `T`：温度（Temperature）
- `H`：湿度（Humidity）
- `W`：怪异度（Weirdness）

`D` 是 Minecraft 多重噪声的深度参数，不是方块 `Y` 坐标。实际纵向位置由“建议钻探 Y 轴”控制，使用 Minecraft 1.21.1 的绝对方块高度；区间按现实矿床的相对地质位置压缩到世界高度 `Y=-64` 至 `Y=320`。浅层氧化矿与沉积矿设置在较高 Y 值，热液或硫化物矿设置在较低 Y 值，绿宝石矿设置在高山地层。

数值区间均为闭区间；`D=0 或 1` 表示接受两种对应的多重噪声深度值。

## 煤

### 褐煤矿脉 `lignite_vein`

| 项目 | 配置 |
| --- | --- |
| 现实分布 | 低煤化程度的沉积煤层，常位于近地表或较浅沉积盆地。 |
| 六项函数 | `C=[-0.1100, 0.3000]`；`E=[0.0500, 1.0000]`；`D=0 或 1`；`T=[-0.1500, 0.5500]`；`H=[0.1000, 1.0000]`；`W=[-0.2666, 0.2666]` |
| 建议钻探 Y 轴 | `Y=48` 至 `Y=96` |
| 量产产出 | `4-13 / min` |
