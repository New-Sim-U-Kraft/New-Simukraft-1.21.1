# 虚拟矿区勘探指南

## 矿区是什么

主世界中的矿物由虚拟矿区管理，不会在地下生成额外的矿石方块。矿区是不规则的连续区域，平均尺度约为 256 格；矿区档案还会按地表群系区分，使矿脉边界尽量贴合群系边界。在同一矿区、同一地表群系内勘探，得到的矿脉信息相同；跨过矿区或群系边界后，矿种才可能改变。

一个“矿区与地表群系”的组合首次被发现时会固定为以下之一：

- 30% 概率没有矿脉。
- 40% 概率有一种矿脉。
- 30% 概率有两种矿脉。

矿种参考当前位置在当前世界 `MultiNoiseBiomeSource` 中的六项气候条件，并排除原版洞穴与深暗之域。模组群系使用自己的参数点，不会再被映射成最近的原版群系。每条矿脉的产量、储量和状态在首次建档后固定，不会因为重新加载区块、重启服务器或数据包重载而改变。

## 适用范围与更新

虚拟矿区适用于主世界多重噪声群系，包括原版高山、樱花林，以及 TerraBlender 等注入到同一张运行时参数表里的模组群系。系统以六项多重噪声 `C/E/D/T/H/W` 判断矿种资格，而不是按群系名称硬编码。

地表采样若恰好落入原版洞穴或深暗之域，系统会在同一张世界参数表中选取最近的可用地表点继续分析；这不会让洞穴或深暗之域变成独立矿区，也不会把模组群系替换成原版气候。非多重噪声的世界生成仍会提示不支持。已经建立的档案不会因这次匹配规则更新而重抽。

不需要为了使用本功能重新生成世界。旧区块会在首次由服务器加载时建立矿区档案；已经建立的档案不会因更新、重启或 `/reload` 重新抽取。安装包含代码更新的版本后，必须完全退出并重新启动客户端或服务器，`/reload` 只会重载数据包配置。

## 使用地质锤

1. 在主世界手持地质锤，对方块右键。
2. 右键位置必须在 `Y=10` 或更高处。
3. 结果会显示在准星右下方，2 秒后自动消失。

地质锤最大耐久为 `800`。每次完成有效勘探都会消耗 `1` 点耐久，无论结果是发现矿脉、未发现浅层矿脉还是矿脉已枯竭；在错误维度、`Y<10`、冷却期间或矿区档案暂时不可用时不会消耗耐久。

地质锤的挖掘速度、可采方块和攻击伤害均与原版铁镐一致。用它破坏方块时，每个方块消耗 `2` 点耐久。

地质锤只显示与浅层相交的矿脉名称、将来钻机的原版产物，以及建议钻探高度。它不显示产量、初始储量或剩余储量，也不会直接采出矿物。

同一矿区有两种可勘探矿脉时，结果会在同一提示中分两行显示。

## 提示说明

| 提示 | 含义 |
| --- | --- |
| `矿脉 -> 产物` | 该矿区存在可用矿脉，后面的 `Y` 区间是建议钻探高度。 |
| 未发现可开采的浅层矿脉 | 当前矿区没有高度范围与浅层相交的矿脉；前往其他矿区继续勘探。 |
| 浅层矿脉已枯竭 | 该矿区对应的矿脉储量已耗尽。 |
| 只能分析 点击位置向下60格内的矿物 | 如果想要获得更深的矿脉需要到更深的地方探矿。 |
| 只能分析主世界矿区 | 下界、末地及其他维度不能使用虚拟矿区勘探。 |
| 当前世界生成方式不支持六项矿脉分析 | 仅在无法取得主世界地表参数时出现；普通原版主世界的高山、樱花林等地表群系均可使用。 |

`Y` 是 Minecraft 的实际方块高度，不是地图高度、海拔描述或群系参数。勘探高度和地质锤的使用高度是两回事：即使矿脉建议在地下钻探，也应在 `Y=10` 以上使用地质锤进行浅层分析。

## 储量与后续钻探

每条矿脉独立拥有 `4,000` 到 `200,000` 个原版产物的总储量。两种矿脉共存时，采空其中一种不会影响另一种。

当前版本已提供地质锤勘探与矿区档案，Simukraft 自有钻机尚未接入。钻机完成后会按这里显示的建议 `Y` 轴读取矿脉并消耗共享储量；储量归零后，该矿脉将永久枯竭。
